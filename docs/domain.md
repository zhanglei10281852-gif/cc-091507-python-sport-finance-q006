# 领域说明

课程签到、转介绍和课包退款共同决定教练与门店的分润，规则又会按生效日切换。签到补录、替补授课和月结更正需要保留关联关系，不能抹掉原始记录。金额精度、锁定批次和反向分录是长期留存的信息。

`reference/domain.json` 保存事件类型、分录类型、结算状态、奖励类型与批次编号格式。正式记录应使用稳定标识，并区分服务时间、接收时间和版本。

## 关键约束

- **不可变台账**：业务事实只追加到 `events.jsonl`，状态由回放重建；冲销、退款、坏账、更正都是新事件与负向分录，原记录通过 `linked_entry_id` 保留关联。
- **生效版本**：授课提成按服务发生日选取规则版本，拉新奖励按成交日选取；拉新仅限会员首单，防止与授课提成重复计算。
- **真实服务归属**：核销时快照教练与门店；替补只影响此后服务；课包转让不回改历史收入。
- **月结边界**：锁定批次编号 `STL-YYYY-MM-CCY` 由期间确定性派生，快照边界是锁定时的台账序号；锁定后的追加只能进入带理由的更正批次 `COR-YYYY-MM-CCY-NN`。
- **金额**：整数分存储，Decimal 比率，四舍五入到分。
